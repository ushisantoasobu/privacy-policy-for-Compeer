**Compeer - Support**

Compeer is an iOS application that lets you instantly switch between multiple audio files to compare them with synchronized playback timing.

**Who is Compeer for?**

Compeer is designed for DTM (desktop music production) users who want to:

*   Compare different versions of a mix (v1, v2, v3...)
*   Listen to "before" and "after" examples from tutorials
*   Switch between a reference track and their own mix
*   Narrow down mastering candidates by ear
*   Evaluate the effect of EQ, compression, and other processing

**Features**

*   Compare 2 to 10 audio files at a time
*   Synchronized playback across all files (same playback position is shared)
*   Instant switching between files with a single tap
*   Blind testing mode (file names are hidden)
*   Save "comparisons" and reopen them later
*   Supports WAV, AIFF, FLAC, ALAC, MP3, AAC, and CAF formats

**Frequently Asked Questions**

*Does Compeer modify or upload my audio files?*

No. Compeer reads audio files in place and never modifies, copies, or uploads them. The Application performs no network requests.

*Why does the app ask for permission to access files?*

Compeer uses Apple's Security-Scoped Bookmark mechanism to remember which files you have selected, so that your saved comparisons remain functional across app launches.

*What happens if I move or delete an audio file?*

If a file you previously added to a comparison is moved or deleted, Compeer will show a warning icon for that file. You can then re-select it from the new location.

*Why is there a limit of 10 files per comparison?*

This limit ensures stable performance on all supported devices.
